# Figma sync (Tokens → Variables)

Archivo fuente:
- packages/tokens/src/tokens.json

## Opción recomendada: Tokens Studio
1) En Figma, instala el plugin Tokens Studio.
2) Configura Sync con GitHub.
3) Apunta al archivo `packages/tokens/src/tokens.json`.
4) Pull tokens.
5) Mapea a Figma Variables (Collections/Modes), por ejemplo:
   - Collection: Gobierno
   - Mode: Light
